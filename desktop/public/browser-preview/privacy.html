UNDERSTAND YOUR SPACE

Privacy should be clear.

The controls around this page are a foundation for a future internal browser. Their scope is deliberately visible.

  • Private preview: navigation stays in memory until this application page ends or the session is purged.
  • Remembered preview: a separate catalog is stored in this browser. Private tabs are never copied into it.
  • Blocking toggles: simulations only. No real ads or trackers are filtered because no external website is loaded.
  • Purge: removes preview tabs and this module’s saved navigation. It cannot inspect or delete external website cookies.
  • Sandbox: this local frame has no script, form, popup, download, same-origin, or parent-access permission.

A preview sandbox is not a complete browser security boundary or an encrypted cookie store.
